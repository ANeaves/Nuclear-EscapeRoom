Emergency Phone Line

The strangest form of Two Factor Authentication we've ever seen.

There is a system of automated messages to relay the proper 5-digit Shutdown Code. This code is based on the Phone Network Serial Number (henceforth called the PNSN) displayed on the LCD Screen.

Step 1:

Follow the instructions below to work out the correct contact to call:

  1. If the PNSN ends with a Vowel: Skip to step 4
  2. If the digits in the PNSN sum to more than 10, contact Zelda H███e
  3. If the PNSN does not contain a 1: skip to step 6
  4. If the PNSN Starts with an F, X, or T, Contact TELE TEX█ ██m
  5. Contact the Lincolnshire Po████r
  6. If the PNSN does not contain any digits, contact Sir Wi█████ ████y
  7. If the PNSN Contains Vowels, contact The Tex ███ █rill
  8. Contact The Princ███ ██ █yrule

Step 2:

Dial the correct contact number and listen for the 5-digit Shutdown Code. This will be repeated at least twice, depending on the number dialed.

The Code Input Dial is a mechanical dial, with buttons to increase and decrease each digit separately. See the diagram below.
